# Banorte

## Descripción

Este proyecto es una aplicación móvil desarrollada en Swift utilizando SwiftUI.

## Características

- **Pantalla de Transferencia**
- **Pantalla de Chat**
- **Automatización de Inversiones**
- **Notificaciones en Tiempo Real**

## Estructura del Proyecto

- `Banorte.xcodeproj`
- `Banorte/`
- `BanorteTests/`
- `BanorteUITests/`
